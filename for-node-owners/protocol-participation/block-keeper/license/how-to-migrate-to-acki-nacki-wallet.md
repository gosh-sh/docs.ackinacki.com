# How to Migrate to Acki Nacki Wallet

To continue using the Acki Nacki Dashboard without MetaMask, you need to migrate to Acki Nacki Wallet.

#### Migration Steps

1. Open the [Acki Nacki Dashboard](https://dashboard.ackinacki.com/licenses).
2. Click Migrate to [Acki Nacki Wallet](https://ackinacki.com/wallet).
3. Enter your existing seed phrase — the one you previously used in the Dashboard.
4. Create and confirm a PIN code to secure access to your wallet.
5. Complete the migration process.

#### After Migration

Once the migration is successful, you can sign in to the Dashboard directly using your seed phrase, without connecting MetaMask.

{% hint style="danger" %}
Important: Keep your seed phrase secure. Never share it with anyone. Enter it only on the official Acki Nacki Dashboard website.
{% endhint %}
